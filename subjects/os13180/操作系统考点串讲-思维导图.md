# 操作系统考点串讲（13180）思维导图

> 依据《操作系统考点串讲》扫描版 PDF 整理；〔〕内为该考点题型标签（单选/填空/简答/综合）。

## 第一章 操作系统概论

### 第一节 操作系统的概念

- **定义**〔单选·填空〕：OS 是计算机系统中的**系统软件**，是一些程序模块的集合
  - 有效组织和管理**硬件及软件资源**
  - 合理组织计算机**工作流程**、控制**程序执行**
  - 向用户提供**服务功能** → 灵活、方便、有效地使用计算机，整个系统高效运行
- **四大特征**〔填空·简答〕（与其他软件不同的特征）
  - **并发性**〔单选·填空〕：系统中同时存在若干运行着的程序，宏观上同时向前推进
    - 两个体现：用户程序 ↔ 用户程序；用户程序 ↔ 操作系统程序
  - **共享性**：OS 程序与多个用户程序共用系统资源（在 OS 控制下实现）
    - 共享资源：中央处理器、内存、外存、外部设备
    - 两种形式：**互斥共享**、**同时共享**
  - **虚拟性**：一种管理技术，物理上的一个实体变成逻辑上的多个对应物（或多个变一个）
  - **异步性**：多道程序下资源有限，进程执行**走走停停**，执行顺序和时间不确定
- **研究 OS 的四个观点**〔简答〕：进程的观点、资源管理的观点、虚拟机器的观点、服务提供者的观点
- **五大功能**〔填空·简答〕
  - **进程管理**（处理器管理）：进程控制、进程同步、进程间通信、调度
  - **存储管理**：内存的分配与回收、存储保护、内存扩充
  - **文件管理**：支持文件的存储、检索、修改；解决共享、保密、保护
  - **设备管理**：除 CPU 和内存以外所有输入输出设备的管理
  - **用户接口**：**命令接口**和**应用程序接口**

### 第二节 操作系统的发展

- **计算机四代**〔单选·填空〕：电子管 1946~1957 → 晶体管 1958~1964 → 集成电路 1965~1970 → 大规模/超大规模集成电路 1971 至今
- **OS 发展六阶段**〔单选·填空〕：手工操作 → 监控程序（早期批处理）→ 多道批处理 → 分时系统 → UNIX 通用操作系统 → 个人计算机操作系统
- **当代方向**〔填空〕：向**大型**（分布式操作系统、机群操作系统）和**微型**（嵌入式操作系统）两个方向发展

### 第三节 操作系统分类

- **三种基本类型**〔单选·填空〕（按用户界面使用环境和功能特征）：批处理、分时、实时
  - 其他类型：个人计算机、网络、分布式、嵌入式等
- **分时系统特点**〔简答〕：多路性、交互性、独占性、及时性
- **实时系统种类**〔简答〕：硬实时系统、软实时系统
- **嵌入式系统特点**〔简答〕：系统内核小、专业性强、系统精简、高实时性、多任务

### 第四节 操作系统设计

- **主要困难**〔单选〕：设计复杂程度高、正确性难以保证、研发周期长
- **设计过程**〔填空·简答〕：**功能设计**（定功能与类型）→ **算法设计**（选算法策略并估算效能）→ **结构设计**（分解、抽象、综合）
- **高质量 OS 五特征**〔填空〕：可靠性、高效性、易维护性、可移植性、安全性
- **软件结构研究对象**〔填空〕：软件各部分**划分的原则**及它们之间的**关系（通信）**，即构成法则和组合方法
- **结构研究目标**〔简答〕：系统模块化、模块标准化、通信规范化
- **四种体系结构**〔填空·简答〕
  - **整体式**（模块组合结构）：优点——结构紧密、接口简单直接、效率高；缺点——模块间转接随意独立性差、数据作全程量处理、常以大型表格为中心需全局中断（限制并发性）、可适应性差
  - **层次式**：按功能流图调用次序分层，**单向依赖**（只允许上层/外层调用下层/内层）
  - **客户/服务器（微内核）**：典型——Mach、Windows NT 早期版本；OS 分为若干小的自包含**服务进程**运行于独立用户进程，规范一致地收发消息；缺陷主要是效率
  - **外核结构**：内核仅负责简单的申请、释放和复用硬件资源，抽象全部在用户空间运行
- **UNIX**〔单选·填空〕：多用户、多任务，很强的**可移植性**和**开放性**
- **Linux 四部分**〔填空〕：内核、Shell、文件系统、用户应用程序
- **Android**〔填空〕：基于 **Linux 内核**的移动操作系统，采用**虚拟机技术**运行应用

### 第五节 操作系统启动

- **BIOS**〔单选·填空〕：一个程序，存储在 BIOS 芯片中
- **启动四部分**〔单选·填空〕：BIOS 自检 → 系统引导 → 启动内核 → 初始化系统
- **典型程序执行流程**〔简答〕：①用户通过 OS 启动程序 ②从磁盘加载到内存 ③分配资源（CPU 时间、内存空间、I/O 设备）④CPU 按顺序执行指令 ⑤与 OS 交互请求服务（读写文件、访问网络）⑥执行完毕 OS 回收资源

## 第二章 操作系统运行环境与运行机制

### 第一节 计算机系统的层次结构

- 所有子系统包括在**硬件（子）系统**和**软件（子）系统**两个层次〔单选·填空〕
- **硬件系统**〔单选·填空〕：中央处理器、内存、外存储器（磁盘、磁带等）、输入输出设备（键盘、鼠标、显示器、打印机等）
- **软件系统三层次**〔填空〕：系统软件、支撑软件、应用软件

### 第二节 中央处理器

- **CPU 组成**〔单选·填空〕：**运算器**（算术与逻辑运算，计算核心）、**控制器**、一系列**寄存器**、**高速缓存**
- **两类寄存器**〔单选·填空〕
  - 用户可见寄存器：对所有程序可用、机器语言直接引用；含数据寄存器、地址寄存器、条件码寄存器
  - 控制和状态寄存器
- **指令执行基本过程**〔填空·简答〕：①取指令（PC 自动变下一条指令地址，通常自增 1）②指令存入指令寄存器，解释并执行
- **指令五类**〔单选·填空〕：访问存储器指令、I/O 指令、算术逻辑指令（数据处理指令）、控制转移指令（指定新执行起点）、处理器控制指令（修改处理器状态）
- **特权指令**〔单选·填空〕：只能由操作系统使用；用户只能使用**非特权指令**
- **两种工作状态**〔单选·填空〕：**内核态**（管态/特权态/系统态/核心态，特权级别高）、**用户态**（目态/普通态，特权级别低）
- **程序状态字 PSW**〔单选·填空〕：指示处理器状态；程序计数器指示下一条要执行的指令

### 第三节 存储系统

- **半导体存储器两类**〔单选·填空〕：读写型存储器（任意读写）、只读型存储器（只能读，写入需特殊方法）
- **存储系统设计三问题**〔填空〕：容量、速度、成本
- **界地址寄存器（界限寄存器）**〔单选·填空〕：存储保护技术；一对界限寄存器存作业内存的下限地址和上限地址（下限寄存器、上限寄存器）

### 第四节 中断机制

- **中断定义**〔单选〕：CPU 对系统中或系统外**异步事件**的响应；异步事件＝无一定时序关系的随机发生的事件
- **中断作用**〔简答〕：充分发挥处理器使用效率；提高系统的实时能力
- **按激发手段分两类**〔单选·填空〕：**强迫性中断**、**自愿性中断**
- **强迫性中断包括**〔简答〕：程序性中断、时钟中断、输入输出（I/O）中断、控制台中断、硬件故障中断
- **中断系统两大组成**〔单选·填空〕：**硬件中断装置**、**中断处理程序**
- **多级中断作用**〔简答〕：①按紧急程度和重要性划分级别 ②解决同等重要的多个中断同时到达时先处理谁

### 第五节 I/O 技术

- **通道**〔单选·填空〕：独立于处理器、专门负责数据 I/O 传输工作的处理单元
- **DMA（直接存储器访问）**〔单选·填空〕：通过系统总线中的独立控制单元——**DMA 控制器**，自动成块传送内存和 I/O 单元间数据
- **缓冲区**〔单选·填空〕：硬件设备间数据传输时暂存数据的存储区域；三种采用场合：处理器与内存之间、处理器和其他外部设备之间、设备与设备之间的通信上——都是解决**速度不匹配**

### 第六节 时钟

- 按时钟类型〔单选·填空〕：**硬件时钟**、**软件时钟**
- 按用途〔单选·填空〕：**绝对时钟**、**相对时钟**

### 第七节 系统调用

- **定义**〔单选〕：用户在程序中调用操作系统所提供的一些**子功能**
- **五大分类**〔简答〕：进程控制类、文件操作类、进程通信类、设备管理类、信息维护类

## 第三章 进程/线程模型

### 第一节 进程的基本概念

- **进程定义**〔单选·填空〕：具有一定独立功能的程序在某个数据集合上的**运行活动**；OS 进行**资源分配和调度**的独立单位；**程序是静态的，进程是动态的**
- **进程六特征**〔填空·简答〕：并发性、动态性、独立性、交互性、异步性、结构性（由**程序、数据、进程控制块**三部分组成）
- **三状态模型**〔单选·填空·综合〕
  - **运行态**：已获得并在 CPU 上执行；单 CPU 系统中最多一个
  - **就绪态**：具备运行条件但未获 CPU；可以有多个
  - **阻塞态**（等待/封锁状态）：等待某事件发生而暂时不能运行
  - 转换：就绪→运行（被调度程序选中）、运行→就绪（时间片用完）、运行→阻塞（等待某事件发生）、阻塞→就绪（等待的事件已发生）
- **五状态模型**〔综合〕：三态 + **创建**（创建进程→提交进程→就绪）、**退出**（运行→释放进程→退出）
- **七状态模型**〔综合〕：五态 + **就绪挂起**、**阻塞挂起**（挂起/激活转换）
- **进程控制块 PCB**〔单选·填空〕：内容分**调度信息**和**现场信息**两大部分
  - 进程 = 程序 + 数据 + PCB
  - PCB 组织方式：线性方式、索引方式、链接方式
- **进程队列三类**：就绪队列、等待队列、运行队列

### 第二节 进程控制

- **原语定义**〔填空〕：由若干条指令组成的一个指令序列，用来实现某个**特定的操作功能**
- **进程控制原语**〔单选·填空〕：创建原语、撤销原语、挂起原语、激活原语、阻塞原语、唤醒原语、改变进程优先级原语等

### 第三节 线程的引入及基本概念

- **线程定义**〔单选〕：引入线程的 OS 中，线程是**进程中的一个实体**，是 **CPU 调度和分派的基本单位**
- **线程属性**〔简答〕
  - ①每个线程有唯一标识符和线程描述表（记录寄存器及栈等现场状态）
  - ②不同线程可以执行相同的程序
  - ③同一进程的各线程**共享该进程的内存地址空间**
  - ④线程是处理器的独立调度单位，可并发执行（单处理器交替占用；多处理器同时占用不同处理器）
  - ⑤创建后开始生命周期直至终止，经历阻塞、就绪、运行等状态变化
- **引入线程的好处**〔简答〕：①创建线程花费时间少（不需另行分配资源）②线程间切换花费时间少 ③同进程线程共享内存和文件，通信无须调用内核、更简便快速 ④线程能独立执行，充分发挥处理器与外部设备的并行工作能力
- **线程 vs 进程**〔填空〕：线程是 **CPU 调度**的基本单位；进程是**资源分配**的基本单位

### 第四节 线程的实现和实例

- **线程三类**〔单选·填空〕：用户级线程、内核级线程、混合方式实现的线程
- **协程**〔单选·填空〕：运行在线程之上的**轻量级线程**；执行完成后可选择主动退出，让另一个协程运行在当前线程之上

## 第四章 进程/线程调度

### 第一节 进程调度的基本概念

- **进程调度＝处理机调度**；进程调度程序是**操作系统的真正核心**，直接负责 CPU 的分配〔单选·填空〕
- **主要功能**〔简答〕：保存现场、挑选进程、恢复现场
- **调度时机**〔简答〕：创建进程、任务完成、等待资源、中断发生、运行到时
- **CPU 两级调度**〔单选·填空〕：进程调度 + 作业调度

### 第二节 进程调度算法的设计思路

- **调度策略选择**〔简答〕：设计目标、公平性、均衡性、统筹兼顾、优先级、开销
- **性能评价标准**〔简答〕：CPU 利用率、吞吐量、周转时间、就绪等待时间、响应时间

### 第三节 经典进程调度算法〔单选·简答·综合〕

- ①先来先服务调度（**最简单**，"排队买票"〔单选·填空〕）②时间片轮转调度 ③优先级调度 ④最短作业优先调度 ⑤最短剩余时间优先调度 ⑥多级队列调度 ⑦多级反馈队列调度

### 第四节 其他进程调度算法

- **保证调度**〔单选·填空〕：向用户做出明确的**性能保证**，然后去实现
- **彩票调度**〔单选·填空〕：一种**概率**调度算法

### 第五节 操作系统调度算法实例

- **BSD UNIX**〔单选·填空〕：采用**多级反馈队列法**，每个优先级队列中采用**轮转**
- **Windows**〔单选·填空〕：优先级组织成两段（两类）：**实时**和**可变**

### 第六节 多处理器调度算法

- **多处理器系统种类**〔单选·简答〕：①松耦合、分布式多处理器、集群 ②专门功能的处理器 ③紧耦合多处理器
- **专用处理器分配**〔单选·填空〕：**组调度**的一种极端形式——应用程序执行期间把一组处理器专门分配给它

### 第七节 实时调度算法

- **静态表驱动调度**〔单选·填空〕：适用于**周期性任务**
- **优先级反转**〔单选·填空〕：任何基于优先级的**可抢占**调度方案中都能发生的现象，与实时调度的上下文关联特别大

## 第五章 存储管理

### 第一节 概述

- **内存空间**〔单选·填空〕：由存储单元（字节或字）组成的**一维连续地址空间**
  - **系统区**：存放 OS 常驻内存部分，用户不能占用
  - **用户区**：分配给用户，装入存放用户程序和数据
  - 内存管理实质＝管理用户区 + 协调公共代码和数据的使用
- **内存分配两种方式**〔填空·简答〕：静态分配、动态分配
- **内存共享**〔填空〕：两个或多个进程共用内存中相同区域；共享内容＝**代码共享**＋**数据共享**；代码共享要求**纯代码**（运行中不会改变）
- **地址重定位**〔单选·填空〕：逻辑地址→绝对地址，又称地址转换/地址映射
  - **静态重定位**：装入前集中完成转换，执行中无须再转换
  - **动态重定位**：装入时不转换，执行中每条指令由硬件地址转换机构实时转换

### 第二节 分区管理方案

- **固定分区**〔单选〕：预先划分若干**大小固定**的分区，运行期间不再重新划分；限制可容纳程序大小，必须提供**最大申请量**
- **可变分区**〔填空〕：不预先划分，装入程序时才划分，大小正好等于需求量；个数可变、不确定
- **内存紧凑**〔填空·简答〕：适当时刻进行碎片整理，移动内存中的进程，把空闲碎片合并成连续大空闲区
- **三种分配算法**〔填空·简答·综合〕
  - **最先适应（First Fit）**＝顺序分配算法：顺序查找空闲区表，找到**第一个**满足长度的分割分配；简单、快速
  - **最优适应（Best Fit）**：找到满足长度的**最小**空闲区；最节约空间，但可能形成很多很小的外碎片
  - **最坏适应（Worst Fit）**：找到满足要求的**最大**空闲区；分割后剩余仍较大，还能装入其他程序
- **分区管理优缺点**〔简答〕
  - 优点：简单易行、内存真正成为共享资源、提高吞吐量和缩短周转时间、算法简单表格不多、开销少、保护简单；可变分区利用率比固定分区高
  - 缺点：内存使用仍不充分、**碎片问题**严重（紧凑需移动大量信息浪费 CPU 时间）；不能提供"虚存"、不能扩充；要求程序**一次全部装入**内存

### 第三节 覆盖与交换技术

- **覆盖技术**〔单选〕：程序若干功能上相对独立的程序段，把**不会同时执行**的程序段共享同一块内存区域；未执行的先存磁盘，前一部分执行完后调入覆盖
- **交换（对换）技术**〔填空〕：分时系统中内存总量不够时，把放不下的进程保存在磁盘上，需要时再装入
  - 四个主要问题〔填空〕：换出进程的选择、交换时机的确定、交换空间的分配、换入进程换回内存时位置的确定

### 第四节 虚拟页式存储管理方案

- **虚拟存储技术基本思想**〔单选·简答〕：利用大容量**外存扩充内存**，产生比实际内存大得多的逻辑**虚拟内存（虚存）**，支持多道程序和大型程序运行
- **页式存储管理**〔填空〕：思想首先由**英国曼彻斯特大学**提出，在该校 **Atlas** 计算机上使用；硬件部件＝**存储管理部件**
- **页表**〔单选·简答〕：指出虚拟地址中**页号**与所占**物理页面号**的对应关系；长度由程序页面数决定；是硬件地址转换的依据；查不到页号→产生"**地址错**"程序性中断
- **页表分类**〔简答·综合〕
  - **多级页表**：多数 32 位 OS 用**二级页表**（页表页＋页目录）；第一级存页表页地址，第二级存物理页面号
  - **散列页表**：地址空间大于 32 位时常用；以页号为散列值；每个表项三字段：虚拟页号、所映射的页框号、指向链表下一个元素的指针
  - **反置页表**：每个**物理页框**对应一个表项（存对应虚拟页面地址＋拥有该页面进程的信息）；全系统只有一个页表，需存放**地址空间标志符**
- **转换检测缓冲区 TLB**〔填空〕：用高速缓冲存储器存放当前访问最频繁的少数活动页面的页号，称为"转快"——**快表**
- **缺页异常处理过程**〔简答·综合〕
  - ①按逻辑地址查页表**有效位**，判断该页是否在内存中
  - ②页标志为"0"→形成缺页异常；保留现场，中断装置交换 PSW 让缺页中断处理程序占用处理器
  - ③OS 处理异常，寻找一个空闲物理页面
  - ④若有空闲页，把磁盘上读出的信息装入该页
  - ⑤修改页表及内存分配表，表示该页已在内存
  - ⑥若无空闲页：按算法选择一个已在内存的页面暂时调出；若该页**已被修改过**则须写回磁盘（否则不必）；调出后让出空间存放当前页；调出/装入后都要修改页表及内存分配表
  - ⑦恢复现场，重新执行被中断的指令（此时页面已在内存，可正常执行）
- **页面调度三策略**〔填空·简答〕：**调入策略**（请求调页、预调页）、**置页策略**、**置换策略**（固定分配局部置换、可变分配全局置换、可变分配局部置换）
- **页面置换算法**〔简答〕：理想页面置换 OPT、先进先出 FIFO、第二次机会、时钟 Clock、最近最少使用 LRU
- **影响缺页率的因素**〔简答〕：分配给程序的物理页面数、页面的大小、程序编制方法、页面置换算法的性能
- **虚拟页式优缺点**〔简答〕：优点——不要求连续存放，**解决碎片问题**，提高内存利用率、利于多道程序；缺点——每程序最后一页有**内碎片**（页面大小固定），页面较大时损失仍较大

## 第六章 文件系统

### 第一节 文件管理的基本概念

- **文件**〔单选·填空〕：一组带标识的、在逻辑上有完整意义的**信息项的序列**；文件名由用户在创建时确定、访问时使用（字母数字串，有些系统要求英文字母打头）
- **文件系统**〔单选·填空·简答〕：操作系统中**统一管理信息资源的软件**；管理文件的存储、检索、更新，提供安全可靠的共享和保护手段，方便用户使用
- **文件系统功能**〔简答〕：①统一管理存储空间（分配与回收）②名字→外存地址的映射（**按名存取**、对用户透明）③实现文件信息的共享并提供保护 ④提供方便使用的接口（操作命令、信息存取加工）⑤系统维护及向用户提供信息 ⑥保持执行效率（**OS 接口中比例最大**）⑦提供 I/O 的统一接口
- **外存储设备特点**〔填空·简答〕（与内存比较）：容量大、非易失、速度较慢、成本较低
- **常用存取方法**〔单选·填空〕：**顺序存取**、**随机存取**
- **文件分类**〔单选·填空〕：按用途——**系统文件、库函数文件、用户文件**；按组织形式——**普通文件、目录文件、特殊文件**

### 第二节 文件的逻辑结构和物理结构

- **设计逻辑结构原则**〔单选〕：易于操作、查找快捷、修改方便、空间紧凑
- **逻辑结构三类**〔填空〕（用户看到的组织形式）：无结构的字符流式文件、有结构的定长记录文件、不定长记录文件构成的记录树；定长＋不定长统称**记录式文件**
- **物理结构三类**〔填空·简答〕
  - **顺序（连续）结构**：最简单，逻辑上连续的文件信息依次存放在**连续编号的物理块**中
  - **链接结构**：为每个文件构造所用磁盘块的**链表**；逻辑连续的文件分散放在不连续物理块中
  - **索引结构**：把每个物理块的**指针**集中存放在**索引表**中

### 第三节 文件目录

- **文件控制块 FCB**〔单选·填空〕：系统为管理文件而设置的**数据结构**；为每个文件设置一个 FCB，把所有 FCB 有序组织起来＝**文件目录**
- **FCB 内容**〔简答〕：①文件名 ②文件号 ③用户名 ④文件物理位置 ⑤文件长度 ⑥记录大小 ⑦文件类型 ⑧文件属性 ⑨共享说明 ⑩文件逻辑结构 ⑪文件物理结构 ⑫口令 ⑬保存期限
- **目录结构三种**〔单选〕：一级（单级）目录结构、二级目录结构、多级目录结构
- **目录项**〔单选·填空〕：FCB 设计成定长数据结构的记录存放在目录文件中，每个记录称为目录项
- **目录文件**〔单选·填空〕：多个文件的 FCB 集中组成文件目录，以文件形式保存；是每项记录长度固定的**记录式文件**
- **目录项分解法**〔单选·填空〕（加快检索）：目录项（FCB）分为**符号目录项（次部）**——文件名＋相应文件号；**基本目录项（主部）**——除文件名以外的其他全部信息
- **FAT 文件系统三版本**〔填空〕：FAT12、FAT16、FAT32——取决于用多少**二进制位**表示磁盘块地址

### 第四节 文件存储空间管理

- **磁盘空间分配与回收算法**〔单选·简答〕
  - **位示图**：用一串二进制位（bit）的值反映磁盘空间的分配使用情况
  - **空闲块表**：专为空闲块建立的表，记录全部空闲物理块：第一个空闲块号＋空闲块个数
  - **空闲块链表**：所有空闲块连成链表，首指针指向第一个空闲块，每块含指向下一个空闲块的指针，最后一块指针为空
- **UNIX 空闲块成组链表**〔综合〕：把 n 个空闲块地址存放在第一个空闲块中（其余 n−1 块实际空闲）；每 100 块为一组，第一组 100 个块号放在第二组的头一块中，依次类推，组间形成链接；最后一组块号中第 2 个单元填 **0** 表示到此结束；不足 100 块的组的块号常放在内存的一个专用块中

### 第五节 实现文件系统的表目

- **表目**〔单选〕：用户申请打开文件时，系统在内存中为该用户保存的必要信息，以表格栏目内容形式出现
- **内存中重要表目**〔填空〕：**系统打开文件表**、**用户打开文件表**

### 第六节 文件和目录的操作

- **典型的文件操作**〔简答〕：①建立文件 ②打开文件 ③读文件 ④写文件 ⑤关闭文件 ⑥删除文件 ⑦指针定位
- **建立文件具体步骤**〔简答〕：①检查参数合法性（文件名是否符合命名规则）②检查同一目录下有无重名文件 ③检查目录中有无空闲位置（有些系统还要申请数据块空间：申请一部分或一次性全部申请）④填写目录项内容（文件名、用户名、存取权限、长度置 0、首地址等）⑤返回
- **指针定位工作**〔简答〕：①由 **fd** 检查用户打开文件表，找到对应入口 ②将用户打开文件表中文件读写指针位置设为新指针位置，供后续读写命令存取该指针处文件内容

### 第七节 文件系统的性能

- **磁盘高速缓存基本思想**〔简答〕：在内存中保存一些逻辑上属于磁盘的磁盘块（**块高速缓存**）；读请求先查缓存，命中则直接在内存读；未命中则启动磁盘读入高速缓存再复制到其他内存区域；缓存已满时按一定算法**淘汰**较少使用的磁盘块

### 第八节 文件共享、保护

- **文件共享**〔单选·填空〕：一个文件允许多个用户共同使用
  - 好处：节省存储空间、免除系统复制文件、减少用户重复劳动、减少实际输入输出次数；利用文件共享可实现**进程间相互通信**
- **共享时间段两种情况**〔填空〕：文件可以同时使用、文件不允许同时使用
- **规定用户使用文件权限的方法**〔简答〕：①采用**树形目录结构** ②**存取控制表**

## 第七章 设备管理

### 第一节 设备管理的基本概念

- **输入输出设备（I/O 设备）**〔单选〕：也称**外部设备**（外设），包括计算机系统中除 CPU 和内存储器以外的所有硬件设备和装置
- **设备管理任务**〔填空·简答〕
  - ①I/O 设备常成为系统性能瓶颈（CPU 越快反差越大）——OS 通过**缓冲技术、中断技术、虚拟技术**解决
  - ②对千变万化的设备实现**统一管理**，方便用户使用
  - ③用户对设备的使用必须是**安全的**：数据不能破坏或泄露；多用户多任务下通过协调避免冲突
- **设备分类**〔单选·简答〕
  - 按使用特性：输入设备、输出设备、交互式设备、存储设备
  - 按信息组织方式：**字符设备**、**块设备**
  - 按可同时共享性：**独占设备**、**共享设备**、**虚拟设备**
- **存储设备特性**〔简答〕：可写入性、可读出性、可保存性

### 第二节 设备硬件和设备管理软件的组成

- **设备硬件组成**〔单选〕：**物理设备**＋**电子部件**；物理设备是物质基础，OS 更注重**电子部件的控制方式**
- **I/O 软件四层**〔填空〕：**中断处理层、设备驱动层、设备独立层、用户层**
  - 功能上看：**设备独立层**是 I/O 软件的主要部分；代码量看：**设备驱动层**是主要部分

### 第三节 I/O 设备的控制方式〔单选·填空·简答〕

- **程序直接控制方式（PIO）**：用户进程直接控制处理器进行内存与外设间信息传送；又称"忙—等"方式、轮询方式、循环测试方式；控制者是**用户进程**
- **中断控制方式**：中断服务程序与中断时 CPU 正在执行的进程相互独立、相互不传递数据
- **DMA 控制方式**：数据块传送分三个阶段——**传送前预处理、数据传送、传送后处理**
- **通道控制方式**：按信息交换方式分三种通道——**选择通道、数组多路通道、字节多路通道**
- **通道的功能**〔简答〕：①接受 CPU 指令，按要求与指定外设通信 ②从内存读取属于该通道的指令，执行通道程序，向设备控制器和设备发送各种命令 ③组织外设和内存间数据传送，提供数据缓存空间、提供数据存入内存的地址和传送的数据量 ④从外设得到设备状态信息，形成并保存通道本身的状态信息，按要求送到内存指定单元供 CPU 使用 ⑤将外设的中断请求和通道本身的中断请求按序及时报告 CPU

### 第四节 设备的分配与回收

- **设备分配算法常用的四张表**〔单选〕：**系统设备表、设备控制表、控制器控制表、通道控制表**
- **设备分配方式两种**〔填空〕：**静态分配**、**动态分配**
- **独占设备的分配方法**〔简答〕：①设备的绝对号与相对号 ②设备的指定方式 ③独占设备的分配和释放
- **共享设备使用的具体方法**〔简答〕：①申请设备（被占用则进入设备等待队列，否则分配）②启动设备（I/O 传输）③释放设备（使用结束发出中断信号时，系统唤醒一个等待设备的进程）

### 第五节 磁盘驱动调度

- **信息传输时间三部分**〔单选·简答〕：**寻道时间**（磁头移动到指定磁道/柱面）、**延迟时间**（扇区旋转到磁头下）、**传送时间**（磁头读写完成信息传送）
- **常用移臂调度算法**〔填空〕：先来先服务调度算法、最短寻道时间优先调度算法、电梯调度算法、单向扫描调度算法

### 第六节 缓冲技术

- **按缓冲区个数分类**〔单选〕：**单缓冲、双缓冲、多缓冲、缓冲池**
- **缓冲池中四种工作缓冲区**〔简答〕：收容输入缓冲区 **hin**、提取输入缓冲区 **sin**、收容输出缓冲区 **hout**、提取输出缓冲区 **sout**

### 第七节 虚拟设备技术

- **虚拟设备技术＝SPOOLing 技术**〔单选〕：多道程序设计系统中处理**独占外部设备**的一种方法；提高设备利用率、缩短单个程序的响应时间
- **SPOOLing 系统三部分**〔填空〕：**输入程序模块、输出程序模块、作业调度程序**

## 第八章 进程同步机制与死锁

### 第一节 进程的同步与互斥

- **临界资源**〔单选·填空〕：计算机系统中需要**互斥使用**的硬件或软件资源，如外设、共享代码段、共享数据结构等
- **资源共享程度三个层次**〔单选·填空〕：**互斥、死锁、"饥饿"**
- **彼得松算法**〔填空〕：一种**软件实现**的临界区访问算法；做法是先修改临界区标志、再检查、最后修改者等待
- **信号量机制**〔填空〕：利用操作系统提供的信号量机制，可实现临界资源的**互斥访问**

### 第二节 经典的进程同步问题〔填空·简答〕

- ①简单生产者—消费者问题 ②多个生产者—消费者问题 ③读者—写者问题

### 第三节 死锁

- **死锁定义**〔单选·填空〕：多道程序系统中，一组进程中的每一个进程均**无限期地等待**被该组进程中的另一个进程所占有且**永远不会释放**的资源；处于死锁状态的进程称为**死锁进程**
- **死锁产生的原因**〔简答〕：①**竞争资源**——资源分配时出现失误，进程间对资源相互争夺造成僵局 ②多道程序运行时，**进程推进顺序不合理**
- **死锁产生的必要条件**〔简答〕：**互斥条件、不可剥夺条件、请求和保持条件、循环等待条件**
- **死锁预防**〔单选·填空〕：**防患于未然**——通过设置某些严格的限制，**破坏产生死锁的必要条件**以防止死锁发生
- **死锁避免基本思想**〔简答〕：对进程发出的每一个系统能满足的资源申请进行**动态检查**，根据检查结果决定是否分配：若分配后可能发生死锁则不予分配，否则予以分配（保证系统不进入死锁状态的**动态策略**）
- **死锁的解除方法**〔简答〕：①剥夺资源 ②撤销进程

### 第四节 哲学家就餐问题及其他实例

- **哲学家就餐问题**〔填空〕：操作系统中关于**进程同步与互斥**的经典问题，也是涉及**死锁**的关键问题
